# 灵工发放模版转换工具

一款基于浏览器的在线工具，用于将 CSV/Excel 数据文件快速转换为多个灵活用工平台的导入模版。

## 功能特性

### 智能识别
- 自动识别数据列类型：姓名、身份证、手机号、开户银行、银行卡号、税前金额、性别、开户地/税源地、备注
- 支持 CSV（UTF-8/GBK）和 Excel（.xlsx/.xls）格式
- 多文件上传，自动合并分析

### 目标模版
- **移步到岗**：简洁6列表格
- **身边云**：保留说明行和批次信息
- **云杉公司**：完整配置表和任务清单
- **自定义模版**：自由定义列名和顺序

### 操作流程
1. 上传样例文件
2. 确认列映射关系
3. 选择目标模版
4. 预览并导出

## 使用方法

直接在浏览器中打开 `template-converter.html` 文件即可使用，无需安装任何依赖。

### 上传文件
- 点击上传区域或拖拽文件到上传区域
- 支持同时上传多个文件
- 支持 CSV 和 Excel 格式

### 确认映射
- 系统会自动识别列类型
- 如有误识别，可手动下拉选择正确的字段类型

### 选择模版并导出
- 从预设模版中选择目标平台
- 或使用自定义模版功能
- 点击导出按钮下载转换后的文件

## 技术栈

- HTML5 + CSS3 + JavaScript（原生实现）
- SheetJS（xlsx）用于 Excel 文件解析
- 无需后端，纯前端处理

## 文件结构

```
template-converter/
└── template-converter.html  # 主文件，包含全部代码
```

## 注意事项

- 导出文件格式为 Excel（.xlsx）
- 大量数据时请耐心等待处理完成
- 自定义模版功能支持自由添加/删除字段
